# Firewall Map 0.64_2

简体中文界面使用插件自己的词库，覆盖地图、仪表盘、设置、状态和日志页面。英文界面仍显示英文；不会修改系统 gettext 域、用户配置或原始日志。菜单的日志入口为 `/ui/firewallmap/log`，复用 OPNsense 原有日志 API 和权限；旧的核心日志地址仍可使用，但不提供插件专用的日志翻译。

GeoLite2 下载遇到临时 DNS 错误（EAI_AGAIN）时，等待 2 秒和 5 秒各重试一次；认证、证书和永久域名错误立即返回原错误。原有下载失败退避继续生效。历史警告不会删除，请结合状态页的最近成功更新时间和当前错误判断是否仍存在问题。

验证：Python 全套测试、渲染器与日志显示测试、PHP 语法检查；设备强制更新 City/ASN 数据库，检查状态页和中文页面。签名源升级和回滚见 signed-repository.md。
